# 【MapLibre × PLATEAU】中崎町 水害時の立体避難マップ

▶ デモマップはこちら: https://furuhashilab.github.io/Hackathon_Oct_MoeAnjo/

## 概要
FOSS4G State of the Map Asia 2026 Osaka のメイン会場となった「中崎町」エリア周辺の 3D Webマップである。
中崎町は古民家を改装したレトロなカフェが立ち並ぶ街だが、水害発生時の垂直避難には課題があると考え、PLATEAUの3D都市モデル（LOD2）とMapLibre GL JSを活用して「建物の高さ」を軸とした立体避難マップを作成した。

## 使用技術・ツール
- **MapLibre GL JS**: Webブラウザ上で3D地図を滑らかに描画するためのオープンソースライブラリ。
- **deck.gl**: PLATEAUのような大規模な3Dデータを、地図上に重ねて可視化するための描画ツール。

## 特徴と技術的アプローチ
ただ3Dモデルを表示するだけでなく、データの属性を活用した可視化を行っている。

1. **建物の高さに基づく動的な色分け（3D GIS分析）**
   PLATEAUデータに含まれる計測高さ（`bldg:measuredHeight`）を利用し、一般的な津波避難ビルの基準となる「高さ9m（約3階建て）」以上の建物を水色、9m未満の建物をグレーに色分けした。これにより、避難可能な建物と低層密集エリアが視覚的に一目でわかるようになっている。

2. **公式防災データの統合**
   大阪市北区の公式データである「指定避難所」および「津波避難ビル」の位置情報をマップ上に青いピンとしてマッピングした。

3. **リアルな景観のコントラスト**
   すぐ南側にそびえ立つ梅田の高層ビル群と、中崎町の低層密集エリアの「高低差のコントラスト」を、カメラの初期角度（ピッチ：見下ろす角度、ベアリング：向いている方角）を調整することで、直感的に伝わるように工夫している。

## 振り返りと考察
中崎町エリアを歩いた際は「レトロで素敵な街並み」という印象であったが、今回PLATEAUの高さデータを抽出して3D空間で俯瞰すると、すぐ背後に迫る高層ビル群との極端なスケールの違いや、有事の際の逃げ道の重要性に気づくことができた。
